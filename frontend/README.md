# Frontend

React + TypeScript + Vite. See the [root README](../README.md) for the overview.

## Run

```bash
cp .env.example .env    # VITE_API_BASE points at the backend
npm install
npm run dev
```

Serves on http://localhost:5173.

## Scripts

- `npm run dev`: dev server
- `npm run build`: build to `dist/`
- `npm run lint`: ESLint
